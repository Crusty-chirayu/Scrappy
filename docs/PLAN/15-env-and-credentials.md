## Group A: Needed Immediately (local dev, no real credentials)

These use local/fake values. The codebase provides working defaults for all of these.

### apps/web (.env.local)

```env
# Supabase (local stack - auto-provided by supabase start)
NEXT_PUBLIC_SUPABASE_URL=http://localhost:54321
NEXT_PUBLIC_SUPABASE_ANON_KEY=<auto-generated by supabase start>

# App
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_API_URL=http://localhost:3001

# Integration mode (local uses fake adapters)
INTEGRATION_MODE=local

# Analytics (optional, can be empty in local)
NEXT_PUBLIC_POSTHOG_KEY=
NEXT_PUBLIC_POSTHOG_HOST=https://app.posthog.com
```

### apps/api (.env)

```env
# Supabase (local stack - session mode for workers)
SUPABASE_URL=http://localhost:54321
SUPABASE_ANON_KEY=<auto-generated by supabase start>
SUPABASE_SERVICE_ROLE_KEY=<auto-generated by supabase start - NEVER expose to browser>

# Database direct connection (for pg-boss, migrations)
DATABASE_URL=postgresql://postgres:postgres@localhost:54322/postgres

# Database pooled connection (for API queries - transaction mode)
DATABASE_POOLED_URL=postgresql://postgres:postgres@localhost:54321/postgres?pgbouncer=true

# App
PORT=3001
APP_URL=http://localhost:3000
NODE_ENV=development

# Integration mode
INTEGRATION_MODE=local

# Email (Mailpit local SMTP)
EMAIL_FROM=hello@scrappy.local
SMTP_HOST=localhost
SMTP_PORT=1025
SMTP_SECURE=false

# Billing (fake mode - no real credentials needed)
BILLING_MODE=local
RAZORPAY_KEY_ID=rzp_test_placeholder
RAZORPAY_KEY_SECRET=placeholder_secret
RAZORPAY_WEBHOOK_SECRET=local_webhook_secret

# AI (fake mode - no API calls in local)
AI_MODE=local
GEMINI_API_KEY=placeholder

# Scraping bot identity
SCRAPPY_BOT_USER_AGENT=ScrappyBot/1.0 (+http://localhost:3000/bot)
```

## Group B: Needed Before Staging Deploy

These require real accounts but can be test/sandbox mode.

### Supabase Project

- **Where**: Create at app.supabase.com
- **What to provide**:
  - `SUPABASE_URL` (project URL)
  - `SUPABASE_ANON_KEY` (anon/public key)
  - `SUPABASE_SERVICE_ROLE_KEY` (service role - treat like a root password)
  - `DATABASE_URL` (direct connection string from Settings > Database > Connection string > URI - session mode)
  - `DATABASE_POOLED_URL` (pooled connection string - transaction mode, port 6543)
- **Steps**: Create project -> Settings -> API -> copy keys
- **Cost**: Supabase Pro plan ($25/month) required for production features (PITR, more connections)

### Razorpay (Test Mode for Staging)

- **Where**: dashboard.razorpay.com
- **What to provide**:
  - `RAZORPAY_KEY_ID` (test key starts with `rzp_test_`)
  - `RAZORPAY_KEY_SECRET` (test secret)
  - `RAZORPAY_WEBHOOK_SECRET` (set in Razorpay dashboard under Webhooks)
- **Steps**: Create account -> Settings -> API Keys -> Generate Test Key
- **Mode**: Set `BILLING_MODE=live` to use real Razorpay (even in test mode)

### Gemini API (Google AI)

- **Where**: makersuite.google.com or Google Cloud Vertex AI
- **What to provide**:
  - `GEMINI_API_KEY`
- **Steps**: Create project in Google Cloud -> Enable Generative AI API -> Create API key
- **Mode**: Set `AI_MODE=live` to use real Gemini
- **Cost**: Verify current pricing before enabling (see 08-ai-plan.md estimates)

### Resend (Email)

- **Where**: resend.com
- **What to provide**:
  - `RESEND_API_KEY`
  - `EMAIL_FROM` (verified sender domain)
- **Steps**: Create Resend account -> Add/verify domain -> Create API key
- **Note**: Domain verification requires DNS records to be added

## Group C: Needed at Production Go-Live

These are live accounts with real money/data implications.

### Amazon Associates India (PA-API)

- **Where**: affiliate-program.amazon.in
- **What to provide**:
  - `AMAZON_PA_API_KEY`
  - `AMAZON_PA_API_SECRET`
  - `AMAZON_AFFILIATE_TAG` (your Associate tag, e.g., `scrappy-21`)
- **Steps**:
  1. Create Amazon Associates account
  2. Drive qualifying sales to the account (3-10 sales/month to maintain API access)
  3. Request PA-API access in Associates Central -> Product Advertising API
  4. Generate API keys
- **BLOCKED**: Cannot proceed without meeting qualifying sales threshold first
- **Note**: PA-API may be deprecated or changed; verify current API version before implementation

### Flipkart Affiliate

- **Where**: affiliate.flipkart.com
- **What to provide**:
  - `FLIPKART_AFFILIATE_ID`
  - `FLIPKART_AFFILIATE_TOKEN`
- **Steps**: Register at affiliate.flipkart.com -> Approval -> Dashboard -> API credentials
- **BLOCKED**: Requires affiliate account approval

### Razorpay (Live Mode)

- Same account as test mode
- **What changes**:
  - `RAZORPAY_KEY_ID` -> use live key (starts with `rzp_live_`)
  - `RAZORPAY_KEY_SECRET` -> use live secret
  - `RAZORPAY_WEBHOOK_SECRET` -> update to live webhook secret
  - **Change**: `BILLING_MODE=live`
- **Legal requirement**: Must have completed Razorpay KYC for your business

### Google OAuth for Auth

- **Where**: console.cloud.google.com
- **What to provide**:
  - `GOOGLE_CLIENT_ID`
  - `GOOGLE_CLIENT_SECRET`
- **Steps**: Create OAuth 2.0 credentials -> Set authorized origins and redirect URIs
- **Note**: Configure in Supabase Auth dashboard (Settings -> Auth -> Providers -> Google)

### Posthog (Analytics)

- **Where**: app.posthog.com
- **What to provide**:
  - `NEXT_PUBLIC_POSTHOG_KEY`
- **Optional**: Can skip analytics at launch and add later

### Sentry (Error Tracking)

- **Where**: sentry.io
- **What to provide**:
  - `SENTRY_DSN`
  - `SENTRY_AUTH_TOKEN` (for source map uploads in CI)
- **Steps**: Create Sentry project -> Settings -> Client Keys -> copy DSN

### Custom Domain DNS

- Point `scrappy.in` (or your domain) to Vercel
- Configure `api.scrappy.in` to Fly.io
- Configure `status.scrappy.in` to status page provider
- Configure email DNS records (SPF, DKIM, DMARC) for Resend

## Group D: Business/Legal Decisions Required

These are not technical but are blocking go-live:

### GST Registration

- Register for GST as a business (required for B2B invoicing)
- Obtain GSTIN
- Required for: billing invoices, B2B Extract/Intelligence customers

### Company Registration

- Legal entity required for Razorpay KYC and affiliate programs
- Provide to Razorpay: company registration number, GSTIN, bank account

### Legal Review

- Privacy Policy reviewed and approved by counsel
- Terms of Service reviewed by counsel
- Data Processing Agreement template reviewed by counsel
- Affiliate disclosure language reviewed by counsel
